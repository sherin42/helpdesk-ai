# HelpDesk AI

An AI-powered Django-based Help Desk and Ticket Management System.

## Features

* User, Staff, and Admin roles
* Ticket creation and tracking
* AI-based department prediction
* AI-based priority prediction
* Automatic ticket assignment to least busy staff
* Manual ticket reassignment
* Ticket escalation system
* SLA monitoring and breach detection
* Ticket history tracking
* Comment system
* User and Staff profile management
* Search and filtering
* Department management dashboard

## Tech Stack

* Python
* Django
* SQLite
* Bootstrap 5
* APScheduler
* Scikit-learn
* Pandas
* NumPy

## Installation

```bash
git clone <repository-url>
cd helpdesk-ai
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
